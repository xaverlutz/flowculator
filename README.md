# 🌊 Flowculator

A sleek iOS app for hydraulic engineering calculations — featuring unit conversions, cylinder computations, and motor parameter analysis.

---

## ✨ Features

- 🔄 **Unit Converter** — Convert between pressure, temperature, power, length, and volume units in real time
- 🛢️ **Hydraulic Cylinder Calculator** — Compute piston areas, stroke volumes, forces, speeds, and power from cylinder parameters
- ⚙️ **Hydraulic Motor Calculator** — Determine displacement, flow rate, RPM, torque, and performance for hydraulic motors

---

## 🏗️ Architecture

The app follows **MVVM** with protocol-oriented design, programmatic UIKit layout via **SnapKit**.
